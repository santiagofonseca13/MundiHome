MundiHome es una plataforma inmobiliaria diseñada específicamente para dinamizar el sector de bienes raíces en la región de Zipaquirá y sus alrededores. Su objetivo es facilitar la búsqueda, publicación y gestión de propiedades a través de una experiencia móvil fluida, moderna y eficiente.

A nivel técnico, el sistema está construido bajo una **Arquitectura Modular** y un diseño **orientado a eventos**, lo que garantiza una alta escalabilidad, un mantenimiento estructurado y un rendimiento óptimo al procesar datos en tiempo real.

## 🚀 Características Principales

- **Exploración Regional:** Búsqueda de propiedades hiperlocalizada y optimizada para Zipaquirá.
- **Gestión Ágil:** Interfaz intuitiva para la publicación rápida de inmuebles.
- **Arquitectura Robusta:** Flujo de datos gestionado por eventos para notificaciones y actualizaciones en tiempo real sin sobrecargar el sistema.
- **Experiencia Nativa:** Rendimiento fluido adaptado a dispositivos móviles.

## 🛠️ Stack Tecnológico

  ### Frontend (Aplicación Móvil)
  - **Lenguaje:** Kotlin
  - **Plataforma:** Android Nativo
  - **UI:** View Binding y Componentes de Material Design
  - **Carga de Imágenes:** Librería Glide
  
  ### Backend
  - **Plataforma:** Firebase
  - **Base de Datos:** Firebase Realtime Database
  - **Autenticación:** Firebase Authentication
  - **Almacenamiento de Archivos:** Firebase Storage
